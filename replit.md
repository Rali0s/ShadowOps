# Replit Setup

The project runs as a standard Vite + Express monorepo and does not depend on any hosted databases or third-party services for local development.

## Getting Started
1. Install dependencies with `npm install`.
2. Start the development servers with `npm run dev`.
3. For a production preview, run `npm run build` followed by `npm run start`.

The development server listens on port **5173** by default. No additional configuration or secrets are required.
